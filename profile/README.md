## Descripción del Proyecto

**StockScan** nace con el objetivo de digitalizar y optimizar los procesos diarios de un almacén moderno mediante una interfaz intuitiva, accesible y robusta. El sistema permite gestionar altas y bajas de stock, control de ubicaciones, alertas de inventario mínimo, seguimiento de pedidos y trazabilidad completa de movimientos.

## Stack Tecnológico y Arquitectura

* **Lenguaje Principal:** Java SE
* **Interfaz de Usuario:** Java Swing (componentes personalizados y diseño centrado en la experiencia del operario)
* **Patrones de Diseño:** Modelo-Vista-Controlador (**MVC**) y Data Access Object (**DAO**)
* **Control de Versiones y Metodología:** Git / GitHub Flow con gestión ágil basada en Sprints
